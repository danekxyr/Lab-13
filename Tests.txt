Тест 1:
Исходные данные: 17 5
Ожидаемый результат: q=3 r=2
Фактический результат: q=3 r=2
Статус: совпало

Трассировка переменных для Теста 1 (ввод: 17 5):
1. До ввода: a, b, q, r не инициализированы.
2. После scanf("%d %d", &a, &b): a = 17, b = 5 (возвращено 2, проверка диапазона [-1000..1000] пройдена).
3. Вход в divide(17, 5, &q, &r): параметры функции a = 17, b = 5, q = адрес переменной q из main, r = адрес переменной r из main.
4. Проверка if (b == 0): 5 == 0 ложно, функция продолжает работу.
5. Выполнение *q = a / b: по адресу q записывается 17 / 5 = 3 (в main теперь q = 3).
6. Выполнение *r = a % b: по адресу r записывается 17 % 5 = 2 (в main теперь r = 2).
7. Возврат из divide: функция возвращает 1 (успех).
8. Ветка if (1) в main: выполняется printf("q=%d r=%d\n", q, r) -> на экран выводится "q=3 r=2".
