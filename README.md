# Лабораторная работа № 13

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Возврат нескольких результатов

## Назначение файлов проекта

* **`main.c`** — функция `divide(int a, int b, int *q, int *r)`, возвращающая признак успеха (`1` или `0` при делении на ноль) через `return`, а частное и остаток — через выходные указатели.
* **`self.c`** — функция `min_max(const int a[], int n, int *lo, int *hi)`, которая за один проход находит минимальный и максимальный элементы массива при `n > 0` и не изменяет выходные переменные при `n <= 0`.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов, включая трассировку переменных для первого опыта.

## Ограничения входа

* В `main.c` вводятся два целых числа `a` и `b` в диапазоне от `-1000` до `1000` включительно.
* Выходные переменные `q`, `r`, `lo`, `hi` считываются только после проверки успешного кода возврата (`1`) от функции.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab13
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```

## Пример работы

### Основная программа (`main.c`)
Ввод: `17 5` -> Вывод: `q=3 r=2`

### Самостоятельная работа (`self.c`)
Массив: `{4, -2, 7}`, начальные `lo=99`, `hi=99`:
```text
n=3 -> Успех; lo=-2; hi=7
n=1 -> Успех; lo=4; hi=4
n=0 -> Отказ; lo=99; hi=99
n=-1 -> Отказ; lo=99; hi=99
```
